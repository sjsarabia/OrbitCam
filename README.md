# OrbitCam

OrbitCam is an AI-powered hovering camera designed to follow a user while they livestream. It helps creators record hands-free videos without needing a separate camera operator. The camera follows the user automatically, while a wrist controller allows quick panning. Voice commands let users select distant subjects and adjust the zoom. OrbitCam aims to make livestreaming easier, more flexible, and more affordable by reducing the need for extra filming equipment or staff.
