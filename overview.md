# OrbitCam - Application Features

## 1. Autonomous Follow Module
The camera automatically follows the user while they move.

## 2. Wrist Controller Module
Allows users to quickly pan the camera using a wrist controller.

## 3. Voice Command Module
Allows users to control the camera using spoken commands.

## 4. Subject Selection Module
Lets users select distant subjects using voice commands.

## 5. Zoom Control Module
Allows users to zoom in and out using voice commands.

## 6. Livestreaming Module
Allows users to record and livestream videos hands-free without needing a camera operator.
